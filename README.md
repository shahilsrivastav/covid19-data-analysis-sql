# covid19-data-analysis-sql

📌 Project Title

COVID-19 Data Analysis using SQL

📊 Overview

This project analyzes COVID-19 data using SQL to identify trends in cases, deaths, and vaccinations across countries and time.

🛠 Tools Used
SQL (MySQL)
Excel (for data cleaning)
🔍 Key Analysis
Total cases vs total deaths
Infection rate by country
Death count by continent
Global trends over time
Vaccination progress using window functions
⚙️ Features
Data cleaning and transformation
Use of aggregate functions
Window functions (Rolling vaccination)
CTE (Common Table Expressions)
Creation of reusable SQL views
🌍 Special Analysis
India-specific COVID analysis
Vaccination progress tracking
📁 Dataset
COVID Deaths dataset
COVID Vaccination dataset

(Source: Kaggle / public dataset)

🚀 Key Learnings
Handling real-world messy data
Writing optimized SQL queries
Using advanced SQL features like window functions and CTE
